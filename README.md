## 🤖 Exploring AI-Assisted QA & Automation

I'm exploring how AI-assisted tools can improve test design, browser inspection, and debugging while keeping automated test results deterministic and verifiable.

My focus is on **practical, evidence-based AI assistance**, not claiming fully autonomous testing or production-ready self-healing capabilities before they are implemented and verified.
